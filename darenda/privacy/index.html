Darenda — политика конфиденциальности

Действует с 25 октября 2026 года

Darenda — приложение Nuvqetra LLC для поиска квартир в Дананге, Вьетнам. По вопросам конфиденциальности: support@nuvqetra.com.

Регистрация, аналитика и реклама

Для использования Darenda не нужен аккаунт. В приложении нет рекламных и аналитических SDK, отслеживания пользователей и покупок.

Что хранится на устройстве

Избранное, фильтры, настройки отображения, сохранённые объявления и кэш изображений хранятся на вашем устройстве. Поиск и фильтрация списка выполняются на устройстве. Приложение не отправляет текст поиска и настройки фильтров в API Darenda.

Избранное можно удалить в приложении. Удаление приложения удаляет его локальные данные; созданные средствами iOS резервные копии управляются настройками Apple.

Загрузка объявлений

Для получения объявлений, фотографий и видео приложение обращается к darenda.app и серверам размещения медиа. Запрос отдельного объявления содержит его идентификатор. При сетевом соединении серверы и поставщики инфраструктуры получают техническую информацию, необходимую для передачи ответа, включая IP-адрес. Это следует отличать от локального хранения избранного и истории поиска.

Для защиты API от слишком частых запросов IP-адрес кратковременно используется в счётчике в оперативной памяти. Счётчик работает в минутном окне и удаляется при очистке истёкших окон, как правило не позднее примерно двух минут. Он не записывается в базу пользовательских профилей. Darenda не создаёт историю ваших поисков или рекламные профили на основании этих запросов.

Геопозиция и карты

Darenda использует карты Apple. Доступ к геопозиции запрашивается только при использовании функции показа вашего местоположения. Разрешение необязательно: без него доступен поиск квартир и карта Дананга.

Код приложения не отправляет вашу геопозицию в API Darenda. Обработка данных системными службами карт и геопозиции регулируется политикой конфиденциальности Apple: https://www.apple.com/legal/privacy/.

Разрешение можно изменить в настройках iOS для Darenda.

Перевод описаний

По вашему запросу описание переводится системным переводчиком Apple на устройстве. Darenda не отправляет текст описания в свой API для перевода. Для первой загрузки языковых моделей может понадобиться интернет. Apple может получать технические показатели использования и работы своего API, включая идентификатор приложения и пару языков, но не исходный текст или перевод. На обработку системным сервисом распространяется политика конфиденциальности Apple.

Внешние ссылки и отправка подборки

Кнопки связи открывают Telegram, WhatsApp, Zalo или внешние страницы. Дальнейшая обработка данных регулируется правилами соответствующего сервиса. Darenda не получает ваши переписки с риэлторами. Эта политика описывает нативное приложение iOS. При переходе на веб-сайты могут применяться их собственные технологии, включая веб-аналитику; они не встроены в нативные экраны приложения.

Когда вы сами используете «Поделиться», выбранному вами приложению передаётся ссылка на объявление или подборку. Ссылка на подборку содержит идентификаторы выбранных объявлений; получатель ссылки может посмотреть эту подборку на сайте Darenda.

Обращения в поддержку

Если вы пишете нам по электронной почте, мы получаем адрес отправителя и сведения, которые вы включили в сообщение, и используем их для ответа на обращение. Для вопросов об удалении такой переписки обратитесь по адресу support@nuvqetra.com.

Изменения политики

При изменении работы приложения мы обновим эту страницу и укажем дату новой редакции.
